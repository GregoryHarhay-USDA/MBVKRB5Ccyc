# Pathway Tools Logs

This directory contains Pathway Tools log files for the two PGDB versions in this repository:

- **MBVKRB5Ccyc** — curated PGDB
- **MBVKRB5cyc** — uncurated PGDB

These logs document Pathway Tools processing output, warnings, and status messages associated with each PGDB. They are intended to support comparison, troubleshooting, and record-keeping for database curation work.

## Contents

- Log files generated by Pathway Tools runs
- Supporting notes or summaries related to the curated and uncurated PGDBs
- Any repository-specific log documentation for MBVKRB5Ccyc and MBVKRB5cyc

## Purpose

Use this directory to:

- Review Pathway Tools output for each PGDB version
- Compare curated versus uncurated processing results
- Preserve run history and diagnostics for future reference

- Curated PGDB: **MBVKRB5Ccyc**
- Uncurated PGDB: **MBVKRB5cyc**
