# MBVKRB5Ccyc

Public supplemental data repository for the Pathway Tools **MBVKRB5Ccyc** pathway/genome database, version **1.0.0**.

## Directory structure

Data are organized by version and data type:

- `data/v1.0.0/pathway-tools-logs/` - Pathway Tools log files
- `data/v1.0.0/foldseq-output/` - Foldseek/Foldseq output files
- `data/v1.0.0/pdb-structures/` - Protein Data Bank (PDB) structure files
